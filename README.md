# 乳腺超声轮廓标注

为 Linux / 3D Slicer 5.12.4 编写的 Python 模块。提供 Segment Editor 的 Paint / Erase 和智能轮廓操作，输出为**轮廓线像素**，不填充肿瘤内部。

公开源码不包含病例、表格、日志或自动测试报告。发布前请检查上传文件；`.gitignore` 不会删除已经提交的文件或历史中的个人信息。如果使用清理后的源码创建新仓库，请只复制源码，不复制旧 `.git` 目录。

## 安装

无需编译，也无需安装 Python 包；使用 Slicer 自带的 NumPy、SciPy、VTK 和 Qt。

1. 打开 Slicer 的 **Edit → Application Settings → Modules**。
2. 在 **Additional module paths** 添加包含 `BreastContour.py` 的目录：
   项目中的 `BreastContour` 目录（使用你实际解压位置的完整路径）。
3. 重启 Slicer，在 **Segmentation → 乳腺超声轮廓标注** 中打开模块。

也可仅对本次运行加载模块：

```sh
Slicer --additional-module-path "$PWD/BreastContour"
```

项目附带 CMake 配置用于在 Slicer 开发环境打包；日常使用直接添加模块路径即可。

也可在项目目录执行 `./launch.sh`，启动 Slicer 并直接打开本模块，无需先修改设置。默认使用 PATH 中的 `Slicer`；可通过 `BREAST_CONTOUR_SLICER` 指定可执行文件。

## 数据目录

选择含 `segmentations.xlsx` 的根目录，结构如下：

```text
数据根目录/
  segmentations.xlsx
  2.25.病例ID/
    2.25.病例ID_ORI.dcm
    Segmentation.nrrd       # 医生原始标注，只读
    Segment.nrrd            # 继续标注及输出；可以不存在
    Segment.backup-时间戳.nrrd
```

模块从表格**阶段三**中读取病例 ID 和“备注”列，保留完整备注。支持如 `2类 10-30/60-70/4A类 35-45/90-55` 的合成示例：没有新类别的区间继承前一个类别，倒序范围按 `55–90` 处理，重叠区间同时显示。类别只作提示，不自动改变分段。文档中的范围均为合成示例。

**帧号使用数组索引，从 0 开始。** 表格中的 10 对应帧索引 10，也就是物理顺序的第 11 帧。图像上同时显示两种计数，避免混淆。

图像视图已调整上下方向，保持左右方向不变；图像、医生参考和工作轮廓统一通过同一切片坐标显示。该调整只改变显示方向，不翻转原始数组或已保存的标注像素。

普通编辑模式中，鼠标滚轮向前滚，帧索引增加 1；向后滚，帧索引减少 1，首尾自动限位，不受图像显示方向影响。智能轮廓模式（包括按住空格）中，滚轮继续只调边界容忍度。

## 使用

1. 启动 Slicer 时不会自动导入历史目录，需要点“导入根目录”。之后选择与当前路径不同、且含 `segmentations.xlsx` 的根目录会自动导入；同一路径不重复导入，也可随时用按钮手动刷新。更换目录时仍会提示处理未保存标注，取消后保留原病例并恢复原目录显示。病例列表中的警告和悬停提示列出缺少文件、备注解析等问题。
2. 选择分段，用 Paint 沿肿瘤边缘画线；用 Erase 修正，**Ctrl+Z** 撤销上一步标注（本模块激活时）。画笔初始默认 1.5 像素（已有设置继续保留），橡皮默认 15 像素，分别通过模块的两个直径输入框调整并记忆。支持 0.5–200 像素，步长 0.1；可直接输入 1.5；缩放图像不改变原始像素直径。
3. 使用帧索引输入框、滑条、左右按钮或图像滚轮逐帧查看；跳转框提供范围端点及医生帧。
4. 医生标注单独显示为半透明参考，可用“显示医生原始轮廓”开关隐藏。医生标过的帧也可重新标注；Paint / Erase / 撤销只作用于你的工作轮廓。
5. 点“检查轮廓”，在问题列表中点击一项跳到对应帧和分段。检查后仍可继续编辑。
6. 点“一键保存”或按 **Ctrl+S**。如有提示，可返回修正，也可保存未完成的工作。切换病例时会提示保存、放弃或取消。

快捷保存仅在本模块激活时接管；离开模块后恢复 Slicer 的普通保存行为。请使用本模块的一键保存输出 `Segment.nrrd`。

病例列表状态：没有工作文件为“未开始”；表格范围内有任意一帧在所有工作分段中均为空时为“待确认”；没有此类空帧时为“已有结果”。医生参考像素不计入工作帧覆盖。导入、打开病例、检查和保存时更新状态；自动创建空白文件不会直接变为“已有结果”，保存未完成结果仍显示“待确认”。每次落笔不扫描全体积，编辑后可点“检查轮廓”刷新状态。“已有结果”只表示范围内工作帧已有像素，不代表轮廓闭合或医学边界已通过验收。

阶段三表格中存在该病例、但备注为空、仅空白字符，或仅标记“1类”（没有帧范围）时，优先显示“无需标注”，不受工作文件是否存在影响；病例仍保留在列表中，打开后面板及图像也显示无需标注。“1 类”、全角“１类”和末尾斜杠也支持。表格中缺少病例记录或其他备注内容解析失败仍保留警告，不按“无需标注”处理；“1类 10-20”这类明确给出范围的内容继续按范围处理。

## 医生参考与独立工作文件

- `Segmentation.nrrd` 只作为医生参考读取，模块保存始终写入 `Segment.nrrd`。
- 如果 `Segment.nrrd` 不存在，自动建立空白工作标注，沿用医生分段名称和颜色；不会复制医生轮廓像素。打开病例时立即创建文件，无需手动创建；创建失败会显示错误。
- 如果已有 `Segment.nrrd`，保留其分段和像素，不合并医生分段、不恢复医生帧、不自动清除历史结果。此前版本已写入的医生像素也不会自动删除，可按需用橡皮重新勾勒。
- 参考层有独立可见性开关，不参与编辑、撤销、轮廓检查或输出。图像标记“医生参考帧 · 可重新标注”。
- 打开参考开关会同时恢复医生各分段的二维可见性、透明度及视图关联；模块激活期间，如显示状态被意外改变，会在原生操作结束后恢复并刷新画面。关闭开关仍会隐藏参考，离开模块暂停自动恢复。此过程仅修复显示，不修改或复制医生像素，也不导出全体积分段数组。
- 画笔和橡皮直径独立记忆，支持小数。关闭 Slicer 的逐点单像素特殊模式，使用二维圆形画笔；像素栅格上的最终线宽仍取决于笔迹位置和方向。
- 落笔后仅标记未保存，不扫描全部医生帧或恢复像素，不创建全体积保护掩膜。完整轮廓检查只在点击检查或保存时运行。
- 覆盖前验证临时 NRRD 能重读、工作轮廓像素和分段属性一致，再备份旧结果并原子替换。写入或验证失败保留旧结果。
- 备份恢复：关闭当前病例，将对应 `Segment.backup-时间戳.nrrd` 复制为同目录的 `Segment.nrrd`，再重新加载。

## 检查判定与边界

前景采用八连通，背景采用四连通，逐个轮廓检查是否围出内部区域；骨架端点和分叉辅助提示。支持同一帧多个闭环，正常的内部空白不是错误。

“疑似未闭合”“存在分支”“接触图像边界”均需人工复核。粗线、自相交或复杂分支会影响数字拓扑判定，模块不会自动补线、填充或确认医学正确性。检查只针对你的工作轮廓。

表格范围内所有分段都没有像素时，单独列为“待确认空帧”；不会把空帧当作未闭合，也不会根据类别猜测应该编辑哪个分段。

第一版针对当前样例的单通道多帧 DCM，沿原始图像平面编辑；不支持彩色超声、动态空间变换或多文件序列。几何不匹配时拒绝静默重采样。输出保留 Slicer 分段信息；暂不导出训练用填充标签。

图像上的中文标注使用明确指定的字体文件：Windows 自动查找系统和当前用户字体目录中的黑体、微软雅黑、宋体或等线；Linux 查找 Noto CJK 或文泉驿字体，Arch 可安装 `noto-fonts-cjk`。替换模块代码后重启 Slicer。字体不存在时，Qt 面板仍显示完整文字。

## 多肿瘤备注

每个范围对应一个独立肿瘤，按备注出现顺序编号，不合并重叠、相邻或相同范围。类别可继承；支持合成示例 `2类 10-20/40-50 3类 70-85` 中没有斜杠的类别切换以及末尾斜杠。

图像右上角每行显示一个肿瘤，当前帧所在行带箭头；重叠范围同时显示。跳转菜单按肿瘤提供起始、结束和范围内医生参考帧。医生 NRRD 的非空帧是参考帧候选，文件没有明确起始/关键/结束角色时不猜测其中哪帧为关键帧；重叠范围中的参考帧同时列入相关肿瘤。范围外参考帧另列。编号仅用于导航和显示，不自动匹配、创建或重命名工作分段。

## 智能轮廓：悬停预览与一键追加

选择编辑器中的“智能轮廓”工具（阈值图标），先选好要写入的分段，然后把鼠标移到肿瘤内部。黄色候选轮廓只用于预览，不修改标注。

也可在图像中**按住空格临时启用智能标注**：按住期间滚轮调节边界阈值，左键确认；松开空格立即清除候选并恢复按下前的工具（Paint、Erase、未选工具或手动选择的智能轮廓）。没有按空格时，原有工具和滚轮操作照常工作。图像有键盘焦点或鼠标位于图像上时可使用；在输入框中输入空格不会切换工具。窗口失焦、打开对话框、退出模块或切换病例也会结束临时模式。

- 滚轮向上增大边界变化容忍度，允许候选跨越更强的灰度变化；向下减小，边界约束更严格。也可直接修改“智能轮廓边界容忍度”。初始 15，范围 1–100，每次调整 1，设置持久记忆。它不是相对鼠标中心灰度的偏差阈值；候选可能随调整改变形状或变为无效。
- “智能轮廓参考区域半径”控制鼠标周围取样范围，范围 0–50 个原始图像像素；0 为单像素，默认 6 为 13×13 像素，半径 r 对应 (2r+1)×(2r+1)，靠边时自动裁剪。设置持久记忆，修改后重新生成候选，不改动已有标注。取样使用区域偏暗灰度的百分位统计，而非算术平均值；该参数与边界容忍度独立。
- 左键把预览的闭合轮廓追加到当前分段、当前帧，保留已有轮廓；Ctrl+Z 撤销一次确认。重复确认同一条已存在的轮廓不占用撤销记录。
- 智能轮廓模式的滚轮仅调容差。帧按钮、输入框和滑条仍可切帧；Paint、Erase 的滚轮继续切帧。
- Esc、鼠标离开图像、切换帧或分段、退出工具会清除候选。继续移动鼠标可重新生成。
- 检查和保存仍使用原有流程，完成后保留此前选择的工具。

算法在当前原始二维帧中进行百分位灰度归一化和平滑，用鼠标附近可配置区域（默认 13×13 像素）的灰度统计寻找低回声起始区域；使用区域取样时，鼠标中心即使落在亮斑上，也不直接以该像素灰度为参考。扩展由局部灰度变化和区域低回声上限共同约束。内部亮斑填洞只用于候选区域计算；细桥或断裂导致多个内部区域时，最多三轮向外补齐连接，必要时用凸包外框包住中间区域，保留原有各部分，并提示人工复核补全部分。最终可确认候选为一个连通闭环、一个内部空洞。预览直接显示轮廓像素，避免斜向连线造成额外小空洞。保存仍为一像素轮廓，不保存填充区域。医生参考不参与候选计算。

接触图像边缘的候选仍会显示，沿图像边缘闭合并允许确认；状态提示“图像外范围未知”，保存后的检查仍提示接触边界。过小、超过图像面积 30% 或补全后仍无单一内部空洞的候选保留范围预览，但禁止确认。没有灰度变化或鼠标不在图像内时无法生成有效范围。

这是无需模型的低回声区域与边界辅助功能。超声边界灰度相近、内部不均匀或散斑较强时，候选可能偏离肿瘤；先查看预览，再确认，必要时用 Paint / Erase 修正。

候选定位在暗区与高回声区交界的亮侧：从暗区核心恢复附近的灰度过渡带，再提取外侧一像素轮廓，尽量将深色区域留在轮廓内部。过渡带恢复限定在核心附近 4 像素，避免跳到邻近独立暗区；黄色预览颜色不变。弱边界和范围较大的渐变仍可能需要调整边界容忍度或手工修正。

相连的更黑色块优先纳入：灰度不高于鼠标附近低回声参考值的像素，不因梯度过大被排除；滚轮主要控制向更亮组织跨越灰度边界的容忍程度。中间被明亮组织隔开的独立暗块不会仅因颜色更黑而自动合并。自动补全只处理已经提取的候选区域，补齐部分不代表已识别到肿瘤边界。
